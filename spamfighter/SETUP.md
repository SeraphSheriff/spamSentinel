# Spamfighter — setup in 5 minutes

You don't need to be a computer person. If you can download a file and
double-click it, you can do this.

## Step 1: Install Python (one time, ~3 minutes)

Python is the free tool that runs Spamfighter. You only install it once.

1. Go to **https://www.python.org/downloads/**
2. Click the big yellow **"Download Python"** button.
3. Run the installer. **IMPORTANT:** on the very first screen, check the
   little box that says **"Add python.exe to PATH"** — then click
   "Install Now."
4. Done. You never have to think about Python again.

## Step 2: Get Spamfighter

Download the `spamfighter` folder and put it somewhere easy to find,
like your Desktop or Documents. (It'll come from GitHub — one download,
no installing.)

## Step 3: Save a spam email as a file

This is the only "new" skill, and it takes 10 seconds:

- **Gmail:** open the spam email, click the **...** menu (top right),
  click **"Download message."** Move the downloaded file into
  Spamfighter's `inbox` folder.
- **Outlook (desktop):** open the email, **File > Save As**, save it into
  the `inbox` folder (it saves as .eml automatically).
- **Outlook (web):** open the email, **...** menu, look for a download /
  save option, move the file into `inbox`.
- **Apple Mail:** select the email, **File > Save As**, choose
  **"Raw Message Source,"** save into `inbox`.
- **Thunderbird:** right-click the email, **Save As > File**, save into
  `inbox`.

Do it for every spam email you want to fight. Ten emails? Save ten files.

## Step 4: Run it

**Windows:** double-click **RUN.bat**.
**Mac/Linux:** double-click **RUN.sh** (or right-click > Open).

A black window opens, thinks for a bit, and closes. That's it.

## Step 5: Open the `reports` folder

For every spam email you get three files:

- **REPORT.md** — plain-English breakdown: who really sent it, what
  server it came from, the red flags. Double-click to read it.
- **COMPLAINT.txt** — a ready-to-send abuse complaint. It tells you the
  exact email address to send it to. Copy the text into a new email,
  **attach the original .eml file**, hit send. That's the punch.
- **NEXT-STEPS.txt** — where else to report it: the FTC, Google Safe
  Browsing, the FBI. Five minutes, no account needed.

Your saved emails automatically move to `inbox/done` so you never
process the same one twice.

## That's the whole thing

Save spam → double-click → send complaints. Every complaint you send
lands on the desk of the company whose servers the scammer abused, and
every FTC/Safe Browsing report raises the scammer's cost of doing
business. You're not deleting spam anymore. You're billing them for it.

Questions? You're already doing more than 99% of people by reading
this far. Go get them.
